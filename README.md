# 走向明天 · 2026 毕业画册

视觉传达设计专业 2026 届毕业作品集。一个可以真的翻开的 3D 毕业画册：

- **桌面场景**：深色木纹桌面、暖黄褶皱吊灯、光锥与地面光池
- **3D 交互**：滚动驱动的镜头推近与书页绕书脊 180° 翻转（纯 CSS 3D Transform）
- **七个跨页**：序 / 个人档案 / 作品目录 / 街角的春天 · 排球 / 山间来信 · 一人一狗 / 墨海青山 / 后记 · 联系
- **交互**：滚轮翻页、点击目录跳转、返回目录、翻页音效、平面/立体切换、全屏、键盘 ← →

## 本地预览

直接打开 `index.html` 即可，或用任意静态服务器：

```bash
npx serve .
# 或
python -m http.server 4173
```

## 技术说明

无框架、无外部依赖、无网络请求。全部插画为手写 SVG（含纸纹与粗糙描边滤镜），
字体使用系统字族栈（思源宋体 / Songti SC / Courier New / Didot）。

> 站点中的人名、作品、实习经历与联系方式均为示例内容。
