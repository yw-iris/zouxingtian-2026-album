# 走向明天 · 2026 毕业画册

视觉传达设计专业 2026 届毕业作品集。一个可以真的翻开的 3D 毕业画册：

- **桌面场景**：深色木纹桌面、暖黄褶皱吊灯、光锥、地面光池，以及在光束里缓慢浮动的尘埃
- **3D 交互**：滚动驱动的镜头推近与书页绕书脊 180° 翻转（纯 CSS 3D Transform）
- **七个跨页**：序 / 个人档案 / 作品目录 / 街角的春天 · 排球 / 山间来信 · 一人一狗 / 墨海青山 / 后记 · 联系
- **交互**：滚轮翻页、点击目录跳转、返回目录、翻页音效、平面/立体切换、全屏、键盘 ← →、顶部阅读进度条

## 装帧工艺

- **纸**：纸纤维肌理（SVG 噪声 + soft-light 混合）覆盖每一张纸面与下方面板
- **书口**：外侧切口用细密横线表现纸叠厚度，装订沟带折痕阴影与装订线
- **光影**：桌面投影不随书页倾斜而始终平贴桌面，翻页时纸面掠过一道高光并落下移动的投影
- **排版**：中文正文首行缩进两字；页码从 01 到 13 连续编号，与目录页码互相对应
- **目录页**附「纸与墨」色卡，记录全册使用的六个颜色

## 本地预览

直接打开 `index.html` 即可，或用任意静态服务器：

```bash
npx serve .
# 或
python -m http.server 4173
```

## 技术说明

无框架、无外部依赖、无网络请求。全部插画为手写 SVG（含纸纹与粗糙描边滤镜），
字体使用系统字族栈（思源宋体 / Songti SC / Courier New / Didot）。
已适配键盘焦点样式与 `prefers-reduced-motion` 降低动效偏好。
